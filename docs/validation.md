# Motion Lab 검증 기록

2026-10-09, 로컬 프로젝트 기준입니다. 수집 기준일은 2026-10-08입니다. 이전 터미널 UI 검증을 현재 에셋 탐색기 검증으로 대체합니다.

## 데이터와 분석

2,153개 항목, 134개 출처 프로젝트: 코드 873개(CSS 738, GLSL 123, SVG 12), 팔레트 992개, 참고 링크 288개입니다. 에셋 탭은 코드와 팔레트 1,865개를 표시합니다. 이번 확장 58개 중 52개는 전체 MIT 고지를 보존한 실제 코드, 6개는 개별 컴포넌트 참고 자료입니다.

전체 분석: CSS/SVG/GLSL 구조 491개, 실제 색상 값 1,374개, 참고 메타데이터 288개. 코드 873개에는 정적 그라디언트 382개가 포함되므로 구조 분석 개수와 다릅니다. 제목·브랜드·태그로 효과를 추론하지 않습니다. 참고 링크에는 효과나 미리보기를 만들어 붙이지 않습니다. 도트 로더의 장식 glyph를 타이포그래피로 오인하던 규칙을 회귀 테스트와 함께 수정했습니다.

원본 ID·코드·라이선스·저작권 고지·출처 정보가 입력과 동일함을 전수 대조했습니다. GLSL의 과거 호스트 설명(분류용 도식)은 실제 셰이더 테스트 장면 설명으로 갱신했습니다. 분석 한국어 문구·JSON·문서는 정상 UTF-8이며 대체 문자(U+FFFD)는 없습니다.

## 실제 UI 확인

검색·5개 교차 필터·종류/출처를 섞은 카드·20개 페이지·상세 패널을 확인했습니다. 마스크와 이미지 교차 결과는 웹과 CLI 모두 GLSL 전환 62개입니다. 조건과 페이지 2는 KO/EN 전환 후에도 유지됐습니다. 마지막 94페이지는 1,861-1,865 항목으로 직접 이동했습니다. 빈 결과의 초기화와 참고 탭 288개 분리를 확인했습니다. 참고 카드 20개에 iframe/canvas/SVG 가짜 미리보기는 없습니다.

방향키만으로 첫 카드 → 필터 요약 → 체크박스, Enter로 조건 선택(일반 모션 82개)을 확인했습니다. 카드 방향키 이동·Enter 상세, 상세 컨트롤 방향키 이동·Enter 코드 탭, 코드 방향키 스크롤·Enter 탭 복귀, Escape 닫기와 원래 카드 포커스 복원을 확인했습니다. 마우스와 Tab 탐색도 지원합니다.

원본 GLSL 복사 6,016자에 transition 함수와 전체 MIT 고지가 포함됐습니다. 검증 전 클립보드 상태로 복원했습니다. Loaders.css의 세 자식 요소와 시차 키프레임, SVG의 세 원과 여섯 애니메이션을 확인했습니다. 아이콘용 CSS가 SVG fill/stroke를 덮던 문제를 수정해 원본 흰색 fill과 stroke 없음의 적용을 재확인했습니다.

390×844 모바일 화면에서 필터 열기·로더 조건·SVG 상세를 확인했습니다. 문서 가로 폭은 뷰포트를 넘지 않았고 보조 글자는 12px였습니다. 임시 뷰포트는 복원했습니다. 시스템 reduced-motion·bfcache 재진입·정적 색상의 재생 버튼 제거는 구현과 정적 검토로 확인했으며 실제 OS 설정 전환이나 외부 사이트 왕복은 실행하지 않았습니다.

## 범위와 게시 상태

미리보기는 원본 동작을 테스트 대상에 적용한 결과입니다. 원작자의 전체 장면·이미지·사이트를 복원하거나 모든 참고 링크의 내부 에셋을 수집한 것은 아닙니다. 남은 288개 링크는 검토 대상이며 로컬 실행 에셋으로 표시하지 않습니다. WebGL 미지원 환경에는 이유를 표시합니다. MP4는 포함하지 않습니다.

Sites 주소만 예약됐으며 원격 게시·업로드는 수행하지 않았습니다. 이전 외부 저장소 업로드는 명시적 전송 승인 부재로 자동 승인 심사에서 거절됐습니다. 원격 호스팅·원격 보안 헤더·외부 AI 클라이언트 설정은 검증하지 않았습니다. MCP는 로컬 stdio이며 전역 설정은 자동 변경하지 않습니다.

## 경량 인덱스 v2

`dist/catalog-index.json`은 3,235,429바이트에서 884,682바이트로 72.66% 줄었습니다. 기존 인덱스에 들어 있던 전체 분석 신호와 미리보기 DOM을 빼고, 후보 검색에 필요한 ID·제목·출처 분류·출처 링크·라이선스 라벨·종류와 네 가지 분석 분류, 근거 종류와 신뢰도를 유지했습니다. 공백을 줄인 UTF-8 JSON이며 `indexVersion: 2`로 구분합니다. 2,153개 항목을 모두 담은 검색용 자료이므로 전체를 화면에 펼치면 여전히 길어집니다.

인덱스 ID의 유일성과 모든 투영 필드가 전체 항목과 동일함을 전수 대조했습니다. 변경 전후 `data/catalog.json`, `dist/catalog.json`, 10개 `dist/collections/*.json`의 SHA-256이 모두 같았습니다. 원본 코드·전체 라이선스·수집 출처·태그는 전체 항목에 보존됩니다. 인덱스에서 후보 ID를 고른 뒤 해당 출처 분류의 컬렉션 또는 로컬 단일 항목 API·CLI·MCP에서 전체 항목을 읽습니다. 기존 빌드·중복 제거·프런트엔드 보존 테스트 1개도 통과했습니다.

사이트 표시 문구의 대시 교체는 표시 계층과 라이브러리가 작성한 안내에만 적용합니다. 이번 빌드·인터페이스·검증 문서와 생성된 `llms.txt`에서 en dash, em dash, 수학 minus가 남아 있지 않음을 확인했습니다. 원본 코드와 라이선스, 수집한 데이터 문구를 일괄 치환하지 않았습니다.

## 메인페이지와 탐색 개선 (2026-10-09)

`index.html`은 메인과 목록의 두 실제 DOM 화면을 제공합니다. `library.html`은 목록으로 바로 진입합니다. Halftone Field Breathe, Four Edge Border Draw, Text Fill Sweep의 원본 CSS 키프레임을 전체 화면 크기와 검정·흰색·Cyan에 맞춰 적용하고 소스의 MIT 고지를 유지했습니다. 홈 화면에서 세 animation 이름과 실제 렌더링을 확인했습니다.

목록 진입은 카탈로그의 `gl-transitions-drop-zone-flicker` 원문 GLSL을 white/black 입력으로 실행한 결과의 휘도를 DOM 가시성 마스크로 적용합니다. 실제 브라우저에서 16개 마스크 프레임 실행, `#library` 진입, 카드 20개와 검색 포커스, 오류 로그 0건을 확인했습니다. 마스크를 해제하고 임시 WebGL 리소스를 정리합니다. 모션 정지 또는 reduced-motion 상태, WebGL 미지원 시 전환을 생략합니다. 실제 모션 정지 진입을 검증했으며 OS reduced-motion 전환과 WebGL 미지원 환경은 정적 검토했습니다.

뒤로가기·브랜드 링크의 메인 복귀, 이전 이동 알림 초기화, 숨겨진 목록 iframe 제거, 방향키와 Enter만으로 홈 KO/EN 선택을 확인했습니다. `#library` 새로고침 후 카드 20개가 정상 로딩됩니다. 초기 카탈로그 요청 실패 후 목록 재시도가 성공하면 `motionlab:catalog-ready`로 홈 셰이더 소스를 갱신합니다. 이 복구는 재현된 Promise 회귀와 수정 코드 검토로 확인했습니다.

20/50/100개 선택의 기본값은 20입니다. 에셋 1,865개의 50개 표시는 38페이지, 100개 표시는 19페이지입니다. 마지막 19페이지의 1,801-1,865 범위와 카드 65개, 다음 이동 비활성화를 확인했습니다. 100개 마지막 페이지에서 50개로 바꾸면 37페이지의 1,801-1,850 범위를 유지합니다. KO/EN과 참고 탭 전환에서 선택값을 유지하고, 참고 자료 288개는 50개 기준 6페이지입니다. 방향키와 Enter로 표시 수 변경도 확인했습니다.

390×844에서 메인 제목·세 효과·모션 정지·목록 진입·표시 수 컨트롤을 확인했습니다. 두 화면 모두 문서 가로 폭이 뷰포트를 넘지 않았으며 임시 뷰포트는 복원했습니다.

AI 연결의 GitHub 링크와 CLI clone 명령은 `https://github.com/JTech-CO/Motion-Lab`을 사용합니다. MCP는 실제 로컬 프로젝트 절대 경로를 넣는 stdio 템플릿이며 GitHub URL을 서버 주소로 쓰지 않습니다. JSON 탭은 정적 데이터 주소, 짧은 API 예시, 실제 자료 3개의 접힌 샘플과 다운로드 버튼을 제공합니다. 버튼 요청 후 현재 화면과 다운로드 요청 알림을 확인했고 오류 로그는 없었습니다. 브라우저 도구의 다운로드 이벤트가 저장 경로를 반환하지 않아 저장된 파일 자체는 별도로 비교하지 않았습니다. 정적 전체·경량 JSON 내용은 빌드 검증으로 대조했습니다.

Python 회귀 검사 23개가 통과했습니다. 루프백 연결이 필요한 HTTP 검사 1개는 샌드박스의 소켓 제한으로 별도 허용 환경에서 실행했습니다. app.js/home.js 문법 검사와 변경 범위 보안 8개 항목 검토에서 추가 문제를 찾지 못했습니다. 읽기 전용 API, 바인딩 SQL, 고정 다운로드 파일 허용 목록, textContent 출력, Host/Origin·CSP와 호출 제한을 유지했습니다. 푸시·업로드·게시와 전역 AI 클라이언트 설정 변경은 수행하지 않았습니다.
