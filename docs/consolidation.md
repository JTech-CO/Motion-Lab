# Motion Lab 중복·유사 항목 병합

2026-10-09 (Asia/Seoul). 원본 6,108개 카탈로그를 **6,074개 탐색 항목**으로 정리했습니다. 같은 코드와 타이밍만 다른 모션은 대표 항목 아래 변형으로 묶고, 유사 팔레트는 각 원래 색 배열을 보존한 계열로 병합했습니다. 원본 출처나 라이선스를 삭제하지 않았습니다.

The catalog now contains **6,074 browse entries from 149 source projects**: 3,357 code assets, 2,429 palettes and 288 references, including 5,786 stored assets. Thirty-four former top-level entries resolve to their preserved original variants.

`6,108 - 9 - 3 - 17 - 5 = 6,074`입니다. 코드 항목은 17개, 팔레트 항목은 17개 줄었으며 참고 링크 288개는 그대로입니다. 54개 그룹 내부 기록에는 각 대표 항목의 기록도 포함됩니다. 이 중 5개는 독립 모션이 아닌 보존용 구성 요소이고, 49개가 완전한 변형으로 탐색 가능합니다. 그룹 내부 기록 수를 최상위 항목 수에 다시 더해 데이터 개수로 표시하지 않습니다.

## 원본과 변형 보존

통합된 항목은 하나의 카드로 표시하며, `variants`에 각 원본의 ID, 코드, 정확한 색 배열, 출처, 라이선스 전문과 검증 근거를 유지합니다. 서로 다른 출처의 코드가 같아도 고지를 합쳐 없애거나 대표 항목의 라이선스로 덮어쓰지 않습니다. 사용할 변형의 라이선스와 필수 고지를 따라야 합니다.

`data/consolidation-policy.json`은 검토한 원본 기록의 코드와 전체 문맥 해시를 고정합니다. 원본 DOM, 색상, 출처 또는 라이선스가 바뀌면 재검토를 요구하며 이전 판단을 자동 재사용하지 않습니다. 빌드를 반복해도 같은 정책을 적용하므로 제거한 개별 카드가 다시 생기지 않습니다.

기존 ID는 별칭으로 남습니다. CLI `get`, MCP `get_motion`, 로컬 `/api/items/ID`에서 기존 ID를 조회하면 원래 ID와 원본 기록에 `canonicalId`를 추가해 반환합니다. 대표 ID는 전체 변형 목록을 포함한 병합 항목을 반환합니다. 정적 JSON 소비자는 카탈로그/index의 `aliases` 또는 `/catalog-aliases.json`으로 대표 ID를 찾은 뒤 전체 기록의 `variants[].id`를 선택할 수 있습니다. 상세 계약은 [interfaces](interfaces.md)에 있습니다.

유사 팔레트의 색상은 평균을 내거나 새로 생성하지 않았습니다. 색 개수, 순서, 역순 의미, 알파 값 및 원래 출처를 각 변형에 그대로 유지합니다. 특히 연결된 유사 관계를 하나의 계열로 묶은 그룹은 모든 구성원의 모든 조합이 같은 거리 기준을 통과했다는 뜻이 아닙니다. 확인된 관계를 통한 탐색 그룹이며, 최종 사용 시 원하는 원본 배열을 선택해야 합니다.

## 전체 구성 복원

SpinKit Chase, SpinKit Swing 및 Three Dots Falling은 원본의 자식 요소, 부속 키프레임과 시차를 복원한 전체 구성으로 대표 항목을 교체했습니다. 원래 별도 항목이었던 구성 요소 5개는 대표 모션 아래에 보존했습니다. 복원은 이미 저장된 핀 고정 원본과 해시·추출 근거를 사용하며 원격 코드를 실행하지 않습니다.

복원한 3개 그룹의 `variants`에는 대표 ID의 복원된 전체 구성 기록이 포함됩니다. 복원 전 대표 항목의 전체 기록은 `repair.originalRecord`에 별도로 남습니다. 원래 구성 요소 기록은 `variantRole: component-part`로 식별합니다. 이 역할의 기존 ID 조회는 원래 부분 기록을 보존하므로, 완전한 모션을 쓰려면 반환된 `canonicalId`를 조회해야 합니다. 구성 요소는 독립 완성 모션처럼 변형 선택기에 노출하지 않습니다.

## 보고서 범위와 한계

[기존 중복·유사성 검토](duplicate-audit.md), `data/duplicate-audit/` 보고서와 전량 판정표는 **커밋 `accd1cd`의 6,108개 병합 전 스냅샷**을 설명합니다. 해당 검토에는 원본 복원이 선행되어야 하는 Chase/Swing 관계와 유지할 변형 판단도 포함되어 있습니다. 그 과거 보고서의 중복 수를 현재 6,074개 카탈로그의 남은 중복 수로 해석하면 안 됩니다.

이번 병합의 적용 대상, 별칭, 원본 보존 및 개수는 [병합 결과 JSON](../data/consolidation-report.json)을 기준으로 확인합니다. 이전 전량 감사 결과는 원본 스냅샷으로 보존하고, 아래의 별도 재검사로 현재 대표 항목을 확인했습니다. 코드 구조·타이밍·색상 거리와 원본 추출 근거를 이용한 정적 판단이며, 브라우저 프레임별 렌더링을 통한 전량 시각 검증은 수행하지 못했습니다.

다음 명령은 현재 대표 기록을 재검사하며, 과거 `data/duplicate-audit/` 파일을 덮어쓰지 않습니다. 남은 같은 기록·고신뢰 정적 유사 관계, 미검토 후보 또는 오류가 있으면 종료 코드 1을 반환합니다.
